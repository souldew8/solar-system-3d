# 🌌 3D Solar System – Interactive Space Simulator

An interactive 3D Solar System built using **React Three Fiber** and **Three.js**.  
This project simulates planetary motion in a realistic space environment with smooth animations and postprocessing effects.

🔗 **Live Demo:** https://solarsystembyman.netlify.app/  
🔗 **GitHub Repository:** https://github.com/souldew8/solar-system-3d

---

## 🚀 Tech Stack

- ⚛ React 19
- ⚡ Vite
- 🌍 Three.js
- 🧩 @react-three/fiber
- 🎨 @react-three/drei
- ✨ @react-three/postprocessing
- 🎬 Framer Motion
- 🧹 ESLint

---

## 🧠 Concepts Implemented

- 3D Scene Rendering using React Three Fiber
- Perspective Camera & Lighting System
- Mesh, Geometry & Material Management
- Texture Mapping for Planets
- Real-time Planet Rotation & Orbit Animation
- useFrame Hook for Animation Loop
- Postprocessing Effects (Bloom / Visual Enhancement)
- Modular React Component Architecture
- Performance Optimized WebGL Rendering

## 🎮 Features

- 🌞 Realistic Solar System layout
- 🌍 Planetary rotation & revolution
- 🎨 Modern dark space-themed UI
- ⚡ Smooth and optimized animation
- 📱 Responsive canvas rendering
